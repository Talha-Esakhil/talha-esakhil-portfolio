# Talha Esakhil Portfolio

A modern and responsive developer Portfolio website built with React, JavaScript, and Vanilla CSS. Showcases my projects, teachnical skills, and contact information.

## Live Demo

https://talha-esakhil-portfolio.netlify.app

## Github Repositery

https://github.com/Talha-Esakhil/talha-esakhil-portfolio

- Responsive design Design for all screen sizes
- Hero section with introduction
- About section
- Project showcase
- Contact section
- Smooth scrolling navigation

## Tech Stack

- React
- JavaScript
- Vanilla CSS
